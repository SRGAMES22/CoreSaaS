# CoreSaaS 🏢

**SaaS de Gestão Completo** (Academias / Clínicas / Escolas)  
Painel administrativo poderoso + App do cliente final.

## Stack

| Camada          | Tecnologia                          |
|-----------------|-------------------------------------|
| Backend         | Ruby on Rails 7.2 (API) + PostgreSQL + JWT |
| Web (Admin)     | Next.js 14 + Tailwind CSS           |
| Mobile (Cliente)| React Native (Expo) + NativeWind    |
| Temas           | Light / Dark / **Maximum Effort** (pago) |

## Funcionalidades Principais

- Painel admin: alunos/pacientes, planos, pagamentos, agenda
- App do cliente: agendamento, histórico, check-in
- Controle de assinaturas e status de pagamento
- **Temas**: Light / Dark / **Maximum Effort** (inspirado em Deadpool & Wolverine)

## Estrutura

```
CoreSaaS/
├── backend/          # Rails API
├── web/              # Next.js (Admin)
├── mobile/           # React Native (Cliente)
└── README.md
```
