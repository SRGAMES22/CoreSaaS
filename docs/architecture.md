# Arquitetura do CoreSaaS

## Visão Geral

- Backend: Rails API-only
- Web: Next.js (painel administrativo)
- Mobile: React Native (app do cliente)
- Auth: JWT
- Temas: Light / Dark / Maximum Effort (pago)
